Componentes

Os componentes do Taberna oferecem recursos reutilizáveis para os conteúdos do site. Com eles, você pode carregar um fragmento, oferecer acesso aos idiomas ou organizar uma sequência de elementos em um carrossel.

Esta página apresenta os componentes disponíveis, seus atributos e exemplos de uso nos arquivos HTML. A aparência pode ser complementada com as configurações de temas e as classes descritas em utilities.

Como os componentes funcionam

Os componentes disponíveis para os fragmentos são registrados como elementos personalizados do navegador. Seus nomes usam o prefixo tbc-*, e o registro acontece em src/web-components.ts durante a inicialização da aplicação.

Elemento Finalidade
tbc-flux Carregar um fragmento HTML no idioma ativo.
tbc-language Apresentar o idioma atual e levar ao seletor de idiomas.
tbc-carousel Organizar elementos em páginas com navegação e reprodução automática opcional.

Nem todo componente Vue do projeto está disponível como uma tag personalizada. As telas de carregamento e erro, por exemplo, são componentes internos montados pela aplicação. Para disponibilizar um novo componente nos fragmentos, é necessário registrá-lo.

Os elementos atuais foram preparados para funcionar dentro do Taberna, com seus estilos e sua inicialização. Os componentes que consultam o idioma dependem do estado compartilhado da aplicação; copiar suas tags para uma página HTML isolada não reproduz esse ambiente.

Como escrever as tags e os atributos

Nos fragmentos HTML, use nomes de atributos em kebab-case e feche explicitamente as tags personalizadas: 

<tbc-language></tbc-language>

Um nome de propriedade como totalPerPage no componente Vue corresponde ao atributo total-per-page no HTML. Valores numéricos são escritos como atributos, por exemplo interval="5000".

Para ativar uma propriedade booleana, use o atributo sem valor. Para manter seu valor padrão falso, omita o atributo: 

<tbc-language flag-only></tbc-language>

Evite escrever flag-only="false" para desativar a opção: esse valor é texto e não representa o booleano falso nesse uso. Basta remover flag-only.

Os fragmentos são inseridos como HTML, sem compilação de expressões ou diretivas Vue. Sintaxes como :interval, v-if, v-for e @click pertencem aos arquivos Vue da aplicação, não aos fragmentos de conteúdo.

tbc-flux: carregar fragmentos

O tbc-flux busca um arquivo de conteúdo e insere seu HTML no local em que o componente foi colocado. A aplicação utiliza esse recurso para montar páginas e complementos, como marca, menus e rodapé.

Atributo Tipo Padrão Finalidade
content-file Texto Não definido Caminho do fragmento dentro da pasta do idioma ativo.

Para reutilizar a marca do site:

<tbc-flux content-file="complements/brand.htm"></tbc-flux>

Com português ativo, o componente procura content/pt-br/complements/brand.htm a partir do endereço-base da aplicação. Nos arquivos do projeto, isso corresponde a public/content/pt-br/complements/brand.htm.

O nome do idioma não deve fazer parte do atributo. Assim, o mesmo componente utiliza o fragmento equivalente quando outro idioma é escolhido.

Regras dos caminhos

O caminho deve terminar em .htm, pode conter subpastas e não pode começar com /. O carregador também rejeita barras invertidas, segmentos vazios e caminhos que contenham ...

O arquivo deve conter um fragmento HTML, sem a estrutura completa de um documento. O carregador possui uma verificação básica para respostas que começam com <!doctype html ou <html, como pode acontecer quando a hospedagem devolve a página principal no lugar de um arquivo ausente.

Comportamento do carregamento

  1. Sem content-file, com atributo vazio ou antes da definição do idioma, o componente permanece vazio e não faz a busca.
  2. Ao mudar o arquivo ou o idioma observado, ele limpa o conteúdo anterior e inicia um novo carregamento.
  3. Falhas de busca ou de validação são encaminhadas à tela de erro da aplicação.
  4. Não há busca automática do mesmo arquivo em outro idioma quando uma tradução está ausente.
  5. Cada instância faz sua própria solicitação; não existe cache ou deduplicação no código do componente.

Também não há cancelamento nem proteção contra respostas antigas em mudanças rápidas de atributo. Essa observação é relevante se você controlar o componente dinamicamente por código.

Evite inclusões circulares: um fragmento não deve carregar a si próprio, nem carregar outro arquivo que volte a incluir o primeiro. Isso pode criar uma sequência contínua de componentes e solicitações.

O HTML é inserido sem sanitização. Utilize fragmentos revisados e mantidos pelo responsável pelo site. Na integração Vue, o componente também emite click, usado pelo menu lateral para fechar após uma interação; a ligação desse evento fica no arquivo Vue.

tbc-language: acesso aos idiomas

O tbc-language apresenta a bandeira e o nome do idioma ativo como um link para #/language.

Atributo Tipo Padrão Finalidade
flag-only Booleano false Ocultar o nome e exibir apenas a bandeira.

Para mostrar bandeira e nome:

<tbc-language></tbc-language>

Para mostrar apenas a bandeira:

<tbc-language flag-only></tbc-language>

O componente consulta os nomes e as bandeiras definidos em public/config/languages.json. Essas informações só ficam disponíveis depois da identificação do idioma.

Ele oferece acesso à página de escolha; não troca o idioma diretamente. A troca ocorre no seletor, salva a preferência no navegador e recarrega a página.

Na integração Vue, o componente emite click. O template padrão utiliza esse evento para fechar o menu lateral quando o visitante acessa o seletor.

Para uma identificação mais clara, prefira a versão com o nome visível quando houver espaço. A versão apenas com bandeira não acrescenta um rótulo textual específico ao link interno.

tbc-carousel: conteúdo em páginas

O tbc-carousel organiza seus elementos filhos em páginas. Cada elemento direto dentro da tag é considerado um item; não existe uma tag adicional de item do carrossel.

Atributo Tipo Padrão Finalidade
total-per-page Número 3 Quantidade de itens por página a partir de 48rem.
interval Número 3000 Intervalo de reprodução automática, em milissegundos. 0 desativa a reprodução automática.

Organizando os itens

Cada item pode reunir título, texto, imagem e links. Para que esses elementos façam parte do mesmo item, coloque-os dentro de um único elemento, como article.

Este exemplo mostra dois itens por página nas telas maiores e troca de página a cada cinco segundos: 

<tbc-carousel total-per-page="2" interval="5000">
  <article>
    <h2>Primeiro projeto</h2>
    <p>Uma apresentação do primeiro trabalho.</p>
  </article>
  <article>
    <h2>Segundo projeto</h2>
    <p>Uma apresentação do segundo trabalho.</p>
  </article>
  <article>
    <h2>Terceiro projeto</h2>
    <p>Uma apresentação do terceiro trabalho.</p>
  </article>
</tbc-carousel>

Colocar todos os artigos dentro de uma única div diretamente sob o carrossel faria essa div contar como um único item. Textos soltos também não substituem os elementos que representam os itens.

Adaptação à largura da tela

Abaixo de 48rem, o componente mostra um item por página. A partir dessa largura, utiliza total-per-page. A última página pode conter menos itens que as anteriores.

Nas telas maiores, a paginação utiliza indicadores clicáveis. Nas menores, aparece um contador da página atual e do total de páginas. Os botões anterior e próximo permitem percorrer as páginas, retornando ao início depois da última e ao final antes da primeira.

Se houver no máximo uma página, os controles de navegação e o rodapé do carrossel ficam ocultos.

Reprodução automática e manual

Para manter apenas a navegação manual, utilize interval="0": 

<tbc-carousel total-per-page="1" interval="0">
  <article>
    <h2>Primeira apresentação</h2>
    <p>Conteúdo que o visitante pode ler no próprio ritmo.</p>
  </article>
  <article>
    <h2>Segunda apresentação</h2>
    <p>Outro conteúdo acessível pelos controles de navegação.</p>
  </article>
</tbc-carousel>

Com intervalo positivo e mais de uma página, o carrossel oferece um botão de pausa e reprodução e uma contagem regressiva até a próxima troca. A navegação para outra página reinicia esse intervalo.

No modo automático inicial, a reprodução pausa enquanto o ponteiro está sobre o carrossel ou o foco permanece dentro dele. Ao sair dessas condições, a contagem pode continuar do tempo restante. Uma pausa feita pelo botão permanece até o visitante acionar a reprodução.

Quando o navegador informa preferência por movimento reduzido, a reprodução automática não começa. Se o visitante acionar Play explicitamente, a reprodução passa a ser permitida e deixa de pausar automaticamente por ponteiro ou foco. A transição visual de deslizamento continua desativada sob movimento reduzido.

Valores e alterações dos itens

total-per-page é arredondado para baixo e limitado a pelo menos 1; valores não finitos resultam em 1. O intervalo não fica abaixo de zero, e valores não finitos desativam a reprodução automática. Para a autoria dos atributos, use números válidos, com quantidade de itens inteira e positiva.

O componente observa a inclusão e a remoção de elementos diretos para atualizar a quantidade de itens. Alterações na largura da tela também recalculam o agrupamento. Ao sair da página, seus observadores, escutas e temporizadores são removidos.

Ícones

Os ícones possuem um registro separado em src/web-icons.ts e usam o prefixo icon-*. O elemento disponível inicialmente é icon-home, baseado no ícone Home de @lucide/vue.

Você pode combiná-lo com um texto que identifique o destino do link:

<a href="#/">
  <icon-home aria-hidden="true"></icon-home>
  <span>Página inicial</span>
</a>

Nesse exemplo, o texto comunica a ação e o ícone funciona como complemento visual. O registro atual não declara atributos específicos para configurar icon-home.

Adicionando ícones conforme a necessidade

Você pode adicionar outros ícones conforme a necessidade do projeto. Para disponibilizá-los nos fragmentos:

  1. 1
    Importe o ícone desejado de @lucide/vue em src/web-icons.ts.
  2. 2
    Acrescente uma entrada ao objeto icons, utilizando a função createIcon existente.
  3. 3
    Escolha um nome com o prefixo icon-*.
  4. 4
    Utilize a nova tag nos fragmentos depois de atualizar a aplicação.

A entrada já existente serve de referência para o padrão de registro:

const icons = {
  ...createIcon('icon-home', Home),
};

Adicionar um ícone ao registro permite usá-lo nos conteúdos; escrever uma tag com um nome novo, sem registrar seu componente, não carrega o ícone automaticamente.

Aparência e acessibilidade

Os elementos personalizados utilizam o DOM da página, sem Shadow DOM. Isso permite compartilhar os estilos globais do Taberna, mas o alcance de uma regra ainda depende de seus seletores e do uso de estilos scoped nos componentes.

Você pode aplicar utilities ao conteúdo dos itens, utilizar as cores do tema e criar estilos globais quando necessário. Não presuma que uma classe aplicada na tag externa controla todos os elementos internos do componente.

O carrossel utiliza --carousel-dot para os indicadores, --carousel-dot-active para o indicador ativo e --carousel-counter para a contagem regressiva. O intervalo de reprodução continua sendo configurado pelo atributo interval, não por uma variável de tema.

Os controles do carrossel são botões com nomes acessíveis e indicação visual de foco. Itens fora da página atual recebem inert e aria-hidden, ficando indisponíveis para interação e ocultos da árvore de acessibilidade enquanto não estão visíveis.

Os rótulos de interface do carrossel ainda estão fixos em inglês. Traduzir o conteúdo dos itens não traduz automaticamente esses rótulos.

Ao preparar o conteúdo, utilize títulos em uma hierarquia adequada, textos claros nos links e descrições alternativas nas imagens. Esses cuidados dependem da autoria dos itens, além dos recursos oferecidos pelo componente.

Criando novos componentes

Se o site precisar de outro recurso reutilizável, crie um componente Vue em src/components/ e registre-o em src/web-components.ts.

Defina o componente e suas propriedades

Como exemplo de estrutura, um componente notice.vue poderia receber uma mensagem: 

<template>
  <p>{{ props.message }}</p>
</template>

<script setup lang="ts">
const props = defineProps({
  message: {
    type: String,
    default: '',
  },
});
</script>

Esse arquivo seria compilado como parte da aplicação. As expressões Vue funcionam nele porque ele é um componente, diferentemente do HTML carregado nos fragmentos.

Registre o elemento

Em src/web-components.ts, importe o novo arquivo:

import Notice from '@/components/notice.vue';

Depois, acrescente esta entrada ao objeto elements, preservando os registros existentes: 

...createElement('tbc-notice', Notice),

Com o registro implementado, o uso no conteúdo seria:

<tbc-notice message="Conheça as novidades do projeto."></tbc-notice>

Esse componente é apenas um exemplo de criação; tbc-notice não faz parte dos elementos atualmente registrados no Taberna.

Cuide da integração

Defina atributos com nomes claros, valores padrão e validação apropriada. Para componentes que recebem conteúdo por slots, considere também como seus estilos alcançarão os elementos fornecidos pelo autor.

Quando um bloco de estilos utilizar diretivas Tailwind, coloque @reference "@/style.css"; no início. Reutilize as variáveis do tema e as utilities para manter a consistência visual.

Os registros atuais não instalam Pinia individualmente em cada elemento personalizado. Componentes que usam as stores dependem da inicialização da aplicação Taberna; se quiser distribuí-los como widgets independentes, essa integração precisará ser preparada separadamente.

Confira o novo elemento em um fragmento real, com seus atributos, conteúdo e interações. Verifique o uso por teclado, a apresentação em diferentes telas e a limpeza de temporizadores ou observadores quando houver. Execute npm run typecheck e npm run build e documente o nome da tag e seus atributos para quem for utilizá-la.
