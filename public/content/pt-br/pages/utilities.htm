Utilitários

As utilities são classes que aplicam regras visuais aos elementos HTML. No Taberna, as classes próprias utilizam o prefixo tbu-* e ficam em src/styles/utilities.css.

Você pode combiná-las para apresentar o conteúdo com as cores, bordas, texturas e espaçamentos do projeto. Esta página explica o que cada classe faz e como utilizá-la nos fragmentos HTML.

A relação entre utilities e tema

O tema define valores compartilhados, e as utilities aplicam esses valores aos elementos. Por exemplo, --color-secondary guarda uma cor no tema, enquanto tbu-secondary-bg utiliza essa cor como fundo. 

<div class="tbu-secondary-bg tbu-primary-text p-4">
  <p>Um conteúdo com fundo secundário e texto principal.</p>
</div>

Nesse exemplo, as duas classes tbu-* aplicam as cores do Taberna. A classe p-4, do Tailwind, acrescenta preenchimento interno.

Alterar a variável no tema atualiza os elementos que a utilizam. Adicionar a classe ao HTML define onde essa configuração será aplicada. Para conhecer os valores e suas opções de personalização, consulte a página de temas.

Como combinar classes

Use as utilities do Taberna junto das classes do Tailwind conforme a responsabilidade de cada uma: 

<section class="tbu-secondary-bg tbu-border tbu-rounded flex flex-col gap-4 p-6">
  <h2 class="tbu-asset-text text-2xl font-bold">Meu projeto</h2>
  <p class="tbu-primary-text">Uma apresentação breve do trabalho.</p>
</section>

Aqui, as classes próprias fornecem cores, borda e arredondamento. As demais organizam os elementos em coluna, criam espaço entre eles e ajustam a tipografia.

Evite combinar classes que disputem a mesma propriedade sem uma intenção clara. A ordem em que os nomes aparecem no atributo class não determina, por si só, qual regra vence; o resultado depende da cascata do CSS gerado.

Os exemplos deste guia são trechos de HTML para usar depois da conversão deste rascunho. O Taberna não interpreta Markdown automaticamente.

Cores de fundo e texto

Cada família de cores oferece uma utility de fundo, uma de fundo com transparência e uma de texto:

Classe Valor utilizado
tbu-primary-bg --color-primary
tbu-primary-bg-opaque --color-primary-opaque
tbu-primary-text --color-primary-soft
tbu-secondary-bg --color-secondary
tbu-secondary-bg-opaque --color-secondary-opaque
tbu-secondary-text --color-secondary-soft
tbu-asset-bg --color-asset
tbu-asset-bg-opaque --color-asset-opaque
tbu-asset-text --color-asset-soft

As classes de texto usam as variações soft, e não a cor base da família. As classes terminadas em bg-opaque, apesar do nome, utilizam cores que atualmente são misturadas com transparência no tema.

Fundos e textos são configurados separadamente. Aplicar uma classe de fundo não escolhe automaticamente uma cor de texto com contraste adequado. 

<div class="tbu-asset-bg-opaque tbu-primary-text p-4">
  <p>Uma informação destacada com fundo translúcido.</p>
</div>

Como o fundo é translúcido, a aparência depende também do que está atrás dele. Confira a leitura do texto na combinação final do site.

Links e elementos de destaque

tbu-asset-link

tbu-asset-link aplica a cor --color-asset-soft, cursor de ponteiro e a duração de transição compartilhada. Ao passar o ponteiro, a cor é misturada com 10% de preto; durante a ativação, com 20% de preto. 

<a class="tbu-asset-link underline" href="#/pages/howwork.htm">
  Conheça o funcionamento do Taberna
</a>

A utility não adiciona sublinhado, tamanho de fonte ou um estilo específico de foco. No exemplo, o sublinhado vem da classe underline. Garanta também uma indicação visível de foco na apresentação final dos links.

tbu-asset-pill

tbu-asset-pill combina texto de destaque, exibição flex, arredondamento rounded-sm, preenchimento horizontal px-2 e vertical py-1, cursor de ponteiro e duração de transição.

No estado normal, não define uma cor de fundo. Ao passar o ponteiro, aplica --color-asset ao fundo e --color-primary ao texto. Durante a ativação, escurece o fundo com uma mistura de 10% de preto. 

<a class="tbu-asset-pill w-fit" href="#/pages/templates.htm">
  Explorar templates
</a>

O arredondamento dessa utility utiliza rounded-sm; ele não é controlado pela variável --rounded. A classe w-fit do exemplo limita a largura do link ao seu conteúdo.

Essas utilities fornecem apresentação. Para navegar, use um link com href; para executar uma ação, use um botão com o comportamento correspondente. Aplicar a classe a uma div não cria navegação, ação ou interação por teclado.

Textos e painéis de código

tbu-asset-code-text

tbu-asset-code-text combina a cor de destaque usada por tbu-asset-text, fonte monoespaçada e peso leve. É útil para nomes de arquivos, comandos e outros termos técnicos dentro de um parágrafo. 

<p>
  Edite o arquivo <code class="tbu-asset-code-text">theme.css</code>
  para personalizar as variáveis do tema.
</p>

tbu-asset-code-panel

tbu-asset-code-panel cria um painel com fundo secundário, preenchimento p-4, tamanho de texto text-lg e organização flex em coluna com gap-1.

Ela também reconhece dois tipos de filhos diretos:

Filho direto Apresentação
span.terminal Usa tbu-asset-code-text e recebe um marcador visual antes do texto.
span.css Usa cor de destaque, fonte serifada, tamanho text-base e peso seminegrito.

Para apresentar comandos:

<div class="tbu-asset-code-panel">
  <span class="terminal">npm install</span>
  <span class="terminal">npm run dev</span>
</div>

O marcador de terminal é inserido por um pseudo-elemento CSS e não faz parte do comando escrito. Ele está configurado para não ser selecionado.

Para apresentar declarações CSS:

<div class="tbu-asset-code-panel">
  <span class="css">--color-asset: var(--color-blue-500);</span>
  <span class="css">--color-asset-soft: var(--color-blue-300);</span>
</div>

Os seletores exigem esses span como filhos diretos do painel. Inserir outro elemento entre o painel e os span impede a aplicação dessas regras específicas.

O painel não executa comandos, não copia texto para a área de transferência e não faz realce automático de sintaxe. Também não preserva espaços e quebras de linha como um elemento pre. Para outros formatos de código, escolha a estrutura HTML e os estilos apropriados. Ao mostrar tags HTML como texto, escape caracteres como < usando &lt;.

Bordas e arredondamento

As utilities de borda aplicam a cor, a espessura e o estilo definidos por --border-color, --border-size e --border-style.

Classe Onde aplica a borda
tbu-border Todos os lados.
tbu-border-top Lado superior.
tbu-border-right Lado direito.
tbu-border-bottom Lado inferior.
tbu-border-left Lado esquerdo.

Para criar uma separação acima de um conteúdo:

<div class="tbu-border-top pt-4">
  <p>Informações complementares.</p>
</div>

O preenchimento do exemplo vem de pt-4; a utility de borda não cria espaço interno.

tbu-rounded aplica o raio definido em --rounded. Você pode combiná-la com uma borda e um fundo: 

<div class="tbu-border tbu-rounded tbu-secondary-bg tbu-primary-text p-4">
  <p>Um painel com a aparência compartilhada do tema.</p>
</div>

O arredondamento não adiciona overflow: hidden. Se precisar recortar o conteúdo interno nos cantos, trate esse comportamento separadamente.

Textura, sombra e sobreposição

tbu-texture

tbu-texture utiliza a imagem definida em --texture e a repete no fundo. A cor de fundo continua sendo responsabilidade de outra regra. 

<div class="tbu-secondary-bg tbu-texture tbu-primary-text p-6">
  <p>Um conteúdo com cor e textura de fundo.</p>
</div>

Definir --texture: none no tema desativa a imagem nos elementos que utilizam essa utility.

tbu-shadow

tbu-shadow aplica duas camadas de sombra com a cor de --shadow-color. Se essa variável estiver ausente, utiliza preto com transparência como alternativa. 

<div class="tbu-secondary-bg tbu-primary-text tbu-rounded tbu-shadow p-4">
  <p>Um painel destacado por uma sombra.</p>
</div>

A cor é configurável pelo tema; deslocamentos e desfoques são definidos na própria utility. A classe não acrescenta borda, fundo ou arredondamento automaticamente.

tbu-backdrop

tbu-backdrop foi criada para fundos de sobreposição, como o que aparece atrás do menu lateral. Ela combina posicionamento fixo, inset-0, textura, desfoque de fundo backdrop-blur-xs, a camada --z-backdrop e a cor --backdrop-color.

Ela é destinada a cobrir a área da tela e pode bloquear interações com o que está abaixo. A abertura, o fechamento, o tratamento de cliques e o gerenciamento de foco pertencem ao componente que utiliza esse fundo; não são implementados pela utility.

Na configuração atual do tema, --backdrop-color referencia --color-secondary-bg, que não está definida. Por isso, sua declaração de cor não fornece um valor válido. A página de temas explica essa limitação e apresenta uma opção de ajuste; textura, desfoque e posicionamento são regras independentes dessa cor.

Espaçamento responsivo

tbu-container aplica preenchimento horizontal usando padding-inline. tbu-block aplica preenchimento vertical usando padding-block.

As duas utilities selecionam variáveis conforme a largura da tela:

Largura tbu-container tbu-block
Abaixo de 48rem --container-sm --block-sm
De 48rem até antes de 64rem --container-md --block-md
A partir de 64rem --container-lg --block-lg

O valor final é calculado multiplicando a variável escolhida por --spacing. Os valores atuais de container são 4, 14 e 24; os de block são 6 nas três faixas. 

<section class="tbu-container tbu-block">
  <h2>Uma região com espaçamento responsivo</h2>
  <p>O preenchimento acompanha os valores definidos no tema.</p>
</section>

tbu-container não define largura máxima nem centraliza o elemento. tbu-block não muda seu tipo de exibição para display: block; seu papel é aplicar o preenchimento vertical. Ambas também incorporam tbu-duration.

No template padrão, a área principal já utiliza tbu-container. Reaplicar a utility dentro dela adiciona outro nível de preenchimento. Use essa composição quando quiser o espaço extra, ou aplique apenas tbu-block e outras classes locais quando o espaço horizontal externo já for suficiente.

Duração das transições

tbu-duration define a duração a partir de --duration e a curva de transição ease-in-out. O valor atual do tema é 200ms.

Ela não cria um estado visual novo nem escolhe explicitamente quais propriedades devem mudar. Combine-a com a propriedade de transição e com os estados desejados: 

<a
  class="tbu-primary-text tbu-duration transition-colors hover:tbu-asset-text"
  href="#/pages/themes.htm"
>
  Explorar o tema
</a>

Nesse exemplo, transition-colors define o grupo de propriedades, hover:tbu-asset-text muda a cor ao passar o ponteiro e tbu-duration fornece o tempo e a curva.

A utility não controla todas as animações do site e não desativa movimento automaticamente conforme a preferência do visitante. Ao criar transições, considere o uso de variantes de movimento reduzido e preserve os estados de foco da interação.

Criando suas próprias utilities

Você pode acrescentar classes reutilizáveis a src/styles/utilities.css com @utility, seguindo o prefixo tbu-* e reutilizando valores do tema.

Por exemplo, esta definição criaria uma utility para pequenos painéis:

@utility tbu-panel {
  @apply tbu-secondary-bg tbu-primary-text tbu-border tbu-rounded p-4;
}

Depois de adicioná-la ao projeto, o uso seria:

<div class="tbu-panel">
  <p>Conteúdo do painel.</p>
</div>

tbu-panel é apenas um exemplo; ela não está definida atualmente. O nome deve ser único e a regra deve reunir um comportamento que faça sentido reutilizar.

Uma utility atende a usos compartilhados. Para estilos específicos de uma página ou estrutura, prefira um seletor próprio em src/style-customs.css, como o projeto já faz com .page-custom.

Ao utilizar diretivas do Tailwind em um bloco de estilos de componente Vue, inclua @reference "@/style.css"; no início. Essa referência permite que o bloco utilize as definições compartilhadas do projeto.

Mantenha os nomes completos das classes nos arquivos de origem e gere um novo build quando adicionar classes ao conteúdo ou novas utilities. Os fragmentos são carregados em tempo de execução, mas o CSS é gerado durante o build; uma classe nova escrita apenas no conteúdo já publicado pode não existir no CSS distribuído.

Exemplo completo

O exemplo abaixo combina utilities em uma seção de apresentação. Ele considera que o espaçamento horizontal já foi aplicado pela área principal do template: 

<section class="tbu-block">
  <div class="tbu-secondary-bg tbu-primary-text tbu-border tbu-rounded tbu-shadow flex flex-col gap-4 p-6">
    <h2 class="tbu-asset-text text-2xl font-bold">Personalize seu Taberna</h2>
    <p>
      Organize o conteúdo, escolha as cores e adapte a apresentação ao seu projeto.
    </p>
    <p>
      As configurações compartilhadas ficam em
      <code class="tbu-asset-code-text">theme.css</code>.
    </p>
    <a
      class="tbu-asset-link w-fit underline focus-visible:outline-2 focus-visible:outline-offset-2"
      href="#/pages/themes.htm"
    >
      Conheça as configurações do tema
    </a>
  </div>
</section>

Confira o resultado com as cores do seu tema, em diferentes larguras e usando o teclado. As utilities ajudam a manter consistência, mas a combinação final deve preservar contraste, foco visível e espaço suficiente para o conteúdo.
