Taberna

Uma base para criar seu site pessoal, portfólio ou página de apresentação, com liberdade para adaptar o conteúdo e o visual ao seu jeito.

O Taberna combina Vue com conteúdo em HTML e funciona inteiramente no navegador. Você pode personalizar o projeto e publicar seu site como arquivos estáticos, sem precisar de um backend.

Conheça o projeto no GitHub

Como funciona

A aplicação cuida da estrutura e da navegação, enquanto o conteúdo fica em fragmentos HTML separados e organizados por idioma. Isso permite atualizar textos e outras informações sem alterar os componentes Vue, além de manter versões do conteúdo para diferentes públicos.

Personalize seu site

Temas

Cores, fontes, espaçamentos e outros detalhes visuais podem ser ajustados para refletir a identidade do seu projeto. As configurações do tema ajudam a manter uma apresentação consistente entre as diferentes regiões do site.

Templates

Os templates organizam o layout, definindo regiões como cabeçalho, conteúdo principal, rodapé e menu lateral. Hoje, o Taberna conta com o default.vue como único template disponível. Novos templates estão nos planos para oferecer outras formas de organizar o site.

Componentes e utilities

Componentes como o carrossel e o seletor de idiomas oferecem recursos reutilizáveis. Para cuidar da apresentação, o projeto combina Tailwind CSS com utilities próprias que ajudam a aplicar cores, espaçamentos, bordas e outros elementos visuais.

Comece seu projeto

Crie um fork do Taberna na sua conta do GitHub para manter sua própria cópia. A partir dela, personalize os textos, a marca, as imagens e o visual, acompanhando suas alterações no repositório.

Quando estiver pronto, o projeto gera os arquivos que você pode publicar em uma hospedagem estática. Assim, você mantém o controle do conteúdo, das personalizações e da escolha de onde hospedar seu site.

Contribua com o Taberna

Sua ajuda é bem-vinda: sugestões, relatos de problemas, melhorias no código, revisão de textos e traduções são formas de participar. Visite o repositório no GitHub para compartilhar ideias e contribuir com o projeto.

Apoie o projeto

Se o Taberna for útil para você e quiser apoiar financeiramente seu desenvolvimento, esse apoio também será muito bem-vindo. A contribuição é opcional, e toda forma de participação tem valor.
