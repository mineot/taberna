Taberna

Uma base para criar seu site pessoal, portfólio ou página de apresentação, com liberdade para adaptar o conteúdo e o visual ao seu jeito.

O Taberna combina uma aplicação Vue com conteúdo organizado em arquivos HTML por idioma. O site funciona no navegador e pode ser distribuído como arquivos estáticos, sem precisar de um backend.

Conheça o projeto no GitHub

Como funciona

A aplicação cuida da estrutura do site, da navegação e do carregamento do conteúdo. Os textos ficam em fragmentos HTML separados, permitindo editar o conteúdo sem alterar os componentes Vue.

Os arquivos estão organizados em public/content/, com uma pasta para cada idioma. Esta página, por exemplo, tem seu conteúdo em public/content/pt-br/home.htm. Outros fragmentos fornecem o conteúdo da marca, dos menus e do rodapé.

Cada fragmento contém apenas o trecho de HTML que será exibido naquela região, sem precisar repetir a estrutura de um documento completo. A ligação entre os fragmentos e as regiões do layout fica em src/AppTemplate.vue.

Os idiomas disponíveis, seus nomes, bandeiras e o idioma padrão são definidos em public/config/languages.json. Cada idioma habilitado precisa ter sua própria pasta com os fragmentos correspondentes. A troca de idioma recarrega a página com o conteúdo escolhido.

Atualmente, a navegação oferece a página inicial e o seletor de idiomas. Criar outro arquivo de conteúdo, por si só, ainda não cria uma nova página navegável.

Instalação e primeiros passos

Para trabalhar no projeto localmente, tenha Git, Node.js 24 e npm instalados.

Clone o repositório e instale as dependências:

git clone https://github.com/mineot/taberna.git cd taberna npm install

Inicie o servidor de desenvolvimento:

npm run dev

Abra no navegador o endereço exibido no terminal. Para começar a personalizar o conteúdo em português, edite os arquivos de public/content/pt-br/, começando por home.htm.

Se outro idioma estiver sendo exibido, use o seletor de idiomas do site para escolher Português (Brasil).

Personalize o tema

O tema é configurado em src/styles/theme.css. Esse arquivo reúne as variáveis que definem cores, fontes, espaçamentos, bordas, arredondamento e outros detalhes visuais.

As cores são organizadas em três famílias: primary, secondary e asset. Elas representam a base visual, os elementos secundários e os destaques do site. Cada família também possui variações para diferentes usos.

Para mudar os destaques de verde para azul, por exemplo, altere estas variáveis dentro do bloco :root existente:

--color-asset: var(--color-blue-500); --color-asset-soft: var(--color-blue-300);

A variável --color-asset-opaque já deriva da cor principal de destaque e acompanha essa alteração.

As famílias de fontes ficam no bloco @theme, e os arquivos de fontes são hospedados junto com o projeto, em public/fonts/. Os espaçamentos das regiões e dos contêineres são controlados pelas variáveis --block-* e --container-*.

As utilities definidas em src/styles/utilities.css utilizam essas variáveis para aplicar o tema ao conteúdo e aos componentes.

Templates

Os templates definem a estrutura do site, organizando regiões como cabeçalho, conteúdo principal, rodapé e menu lateral. Eles ficam em src/templates/ e recebem o conteúdo dessas regiões por meio de espaços chamados slots.

Atualmente, o Taberna conta com o template default.vue, utilizado por src/AppTemplate.vue para montar o layout com os fragmentos de conteúdo. Novos templates estão nos planos para oferecer outras formas de organizar o site.

Componentes e utilities

O Taberna inclui componentes que podem ser usados nos fragmentos HTML:

  1. 1 tbc-flux: carrega um fragmento de conteúdo no idioma ativo.
  2. 2 tbc-language: exibe o idioma atual e oferece acesso ao seletor de idiomas.
  3. 3 tbc-carousel: organiza elementos em um carrossel com navegação e reprodução automática configurável.

Para a apresentação visual, o projeto utiliza Tailwind CSS e utilities próprias com o prefixo tbu-*. Entre elas estão recursos para cores, espaçamento, bordas, links e fundos, como tbu-container, tbu-block e tbu-asset-link.

Faça o projeto ser seu

Uma forma de começar é criar um fork do Taberna na sua conta do GitHub. Assim, você mantém sua própria cópia, registra suas alterações e adapta o projeto ao site que deseja publicar.

Ao seguir esse caminho, use o endereço do seu fork no comando git clone. Depois, personalize os textos, a marca, as imagens, os links e o tema.

Manter sua versão em um repositório também facilita acompanhar o histórico das mudanças e compartilhar melhorias com o projeto original.

Gere e publique seu site

Quando o conteúdo estiver pronto, gere a versão de produção:

npm run build

Esse comando verifica o TypeScript e gera o site na pasta dist/. Para conferir o resultado localmente, execute:

npm run preview

Para publicar, envie o conteúdo de dist/ para uma hospedagem de arquivos estáticos. O servidor de preview serve para conferir o build localmente; a publicação é feita na hospedagem escolhida.

Se o site ficar em um subdiretório, revise os caminhos das imagens e de outros recursos nos fragmentos. Caminhos que começam com /, como /images/logo.png, apontam para a raiz do domínio e podem precisar de ajuste.

Depois de alterar o projeto, gere um novo build para atualizar os arquivos que serão publicados.

Contribua com o Taberna

Sua ajuda é bem-vinda. Você pode contribuir relatando problemas, sugerindo melhorias, revisando textos, ajudando com traduções ou enviando alterações no código.

Use o repositório no GitHub para compartilhar uma ideia, abrir uma issue ou enviar um pull request. Ao relatar um problema, explique o que aconteceu e, se possível, como reproduzi-lo.

Se o Taberna for útil para você e quiser apoiar financeiramente seu desenvolvimento, essa contribuição também será muito bem-vinda. O apoio é opcional, e toda forma de participação tem valor.
