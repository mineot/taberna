Contribute to Taberna

Taberna is an open-source project and is taking its first steps. There is still much to build, improve, and learn, and all help is welcome. Whether with code, ideas, or small adjustments, your contribution can make a difference from the start.

Help with development

You can contribute by fixing problems, improving components, creating new features, or making the project more accessible. Small improvements also have value and are a great way to start.

Share ideas and report problems

Found something that does not work as expected, or had an idea to improve Taberna? Open an issue on GitHub. When reporting a problem, describe what happened, what you expected, and how to reproduce it. Screenshots can help when it makes sense.

Improve the documentation and translations

Clear instructions make the project easier to use. You can review texts, fix examples, suggest explanations, and help with translations. The experience of those who are starting out also helps reveal what needs to be clearer.

How to start

  1. 1
    Access the repository and get to know the project structure.
  2. 2
    Check the existing issues to find discussions related to your contribution.
  3. 3
    For larger changes or new features, open an issue before starting to talk about the proposal.
  4. 4
    To submit changes, fork the project, create a branch, and open a pull request explaining what changed and why.
