Contribute to Taberna

Taberna is an open-source project in its early stages. There is still plenty to build, improve, and learn, and all help is welcome. Whether through code, ideas, or small adjustments, your contribution can make a difference from the start.

Help with development

You can contribute by fixing issues, improving components, creating new features, or making the project more accessible. Small improvements matter too and are a great way to get started.

Share ideas and report issues

Found something that does not work as expected, or have an idea to improve Taberna? Open an issue on GitHub. When reporting a problem, describe what happened, what you expected, and how to reproduce it. Screenshots can help when relevant.

Improve documentation and translations

Clear instructions make the project easier to use. You can review text, correct examples, suggest explanations, and help with translations. The experience of new users also helps reveal what needs to be clearer.

Getting started

  1. Visit the repository and explore the project structure.
  2. Check existing issues for discussions related to your contribution.
  3. For larger changes or new features, open an issue before starting to discuss the proposal.
  4. To submit changes, fork the repository, create a branch, and open a pull request explaining what changed and why.
