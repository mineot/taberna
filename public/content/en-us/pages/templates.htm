Layout and composition

Taberna's layout is built with components. The tbc-layout-linear organizes the header, main content, and footer; navigation and the sidebar are components you combine to suit the site's needs.

The composition lives in src/AppTemplate.vue. This is where you choose the fragments and components for each region. Colors and spacing remain in the theme, and text lives in HTML files.

How the pieces connect

App.vue
  → AppTemplate.vue
    → tbc-layout-linear
      → Header + route content + Footer
    → tbc-sidebar

App.vue wraps this structure in the loading and error widgets. The linear layout lives in src/components/_layout.linear.vue and its styles in src/styles/components/_layout.linear.css.

The header stays at the top while scrolling. The layout has a minimum height of one viewport, and the main area fills the remaining space when content is short. Longer pages expand the structure and use the ancestor container's scrolling.

Linear layout regions

The paths below are relative to the active language's folder, such as public/content/en-us/.

Slot Current content
header-brand complements/brand.htm
header-nav complements/header-nav.htm
Unnamed The current route's page, forwarded through <slot></slot>.
footer-brand complements/brand.htm
footer-nav complements/socials.htm
footer-body complements/footer.htm
footer-copyright complements/copyright.htm

A slot receives HTML, another component, or a fragment loaded by tbc-flux. The slot name does not automatically determine a file: that connection is written in AppTemplate.vue.

Filling slots

To fill the slots of a tbc-* element, use actual elements with the attribute slot. This snippet shows the layout composition inside the template block of AppTemplate.vue: 

<tbc-layout-linear>
  <div slot="header-brand">
    <tbc-flux content-file="complements/brand.htm"></tbc-flux>
  </div>
  <div slot="header-nav">
    <tbc-flux content-file="complements/header-nav.htm"></tbc-flux>
  </div>

  <slot></slot>

  <div slot="footer-brand">
    <tbc-flux content-file="complements/brand.htm"></tbc-flux>
  </div>
  <div slot="footer-nav">
    <tbc-flux content-file="complements/socials.htm"></tbc-flux>
  </div>
  <div slot="footer-body">
    <tbc-flux content-file="complements/footer.htm"></tbc-flux>
  </div>
  <div slot="footer-copyright">
    <tbc-flux content-file="complements/copyright.htm"></tbc-flux>
  </div>
</tbc-layout-linear>

The <slot> in this example belongs to the Vue file and forwards the current page. In an HTML fragment, place the content itself in the unnamed slot. Vue directives and the syntax <template #name> are not compiled in fragments.

The layout declares owner, year and copyright, but the current footer does not use those properties to generate text. Customize complements/copyright.htm, provided to the slot footer-copyright.

Responsive navigation

The header menu lives in complements/header-nav.htm. The component tbc-nav responsive displays nav-wide at widths of at least 48rem and nav-narrow below that width. You provide the content for both: 

<tbc-nav responsive aria-label="Main navigation">
  <div slot="nav-wide">
    <tbc-link href="#/" text="Home"></tbc-link>
    <tbc-link href="#/pages/howwork.htm" text="How it works"></tbc-link>
  </div>
  <div slot="nav-narrow">
    <tbc-link trigger="#sidebar" trigger-prop="show" trigger-value="true">
      <span>Open menu</span>
    </tbc-link>
  </div>
</tbc-nav>

The button assigns true to the property show on the element with id="sidebar". The navigation component does not create the sidebar: it must exist in the composition.

Composing the sidebar

tbc-sidebar provides sidebar-header, the unnamed slot for the body, and sidebar-footer. Here is an example composition: 

<tbc-sidebar id="sidebar">
  <div slot="sidebar-header">
    <tbc-flux content-file="complements/brand.htm"></tbc-flux>
  </div>
  <tbc-flux content-file="complements/sidebar-nav.htm"></tbc-flux>
  <div slot="sidebar-footer">
    <tbc-language lg></tbc-language>
  </div>
</tbc-sidebar>

The panel starts closed and closes through its internal icon or the backdrop. Clicking a body link does not close it automatically in this example: that behavior must be connected in the Vue composition, as with the function closeSidebar from AppTemplate.vue.

Current integration: AppTemplate.vue passes sidebar navigation to the unnamed slot of tbc-sidebar. Its closeSidebar handler sets show to false when a navigation link is clicked.

Using the header and footer separately

You can build another composition with tbc-header and tbc-footer. In the header, branding occupies header-brand and navigation goes in the unnamed slot. In the footer, use footer-brand, footer-nav, footer-copyright and the unnamed slot for the body.

The footer already includes the “Powered by Mineot” link. Its internal links follow normal router navigation; the component has no dedicated scrolling option for clicking the same route again.

Where to customize

Change File or folder
Text, menus, branding, and social links public/content/en-us/complements/
Composition and region fragments src/AppTemplate.vue
Component structure src/components/
Layout, header, footer, and menu styles src/styles/components/
Shared visual values src/styles/theme.css

Reuse components before duplicating their structures. For a new region, adapt the composition and, if necessary, add a slot to the responsible component. When that region loads a fragment, prepare the same path in every enabled language.
