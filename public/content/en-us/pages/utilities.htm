Utilities

The utilities tbu-* apply theme values to HTML elements. Use components prefixed with tbc-* for features such as links, navigation, and carousels; complement their content with utilities for colors, organization, and visual details.

General definitions live in src/styles/utilities/. Styles reused by components live in src/styles/components/. Both are imported by src/style.css.

A complete example

<section class="tbu-panel tbu-rounded tbu-flex-cols">
  <h2 class="tbu-text-asset-hard text-2xl font-semibold">My project</h2>
  <p>A brief introduction to the work.</p>
  <tbc-link href="#/pages/howwork.htm" text="Explore the project"></tbc-link>
</section>

My project

A brief introduction to the work.

The panel provides a background, texture, side border, and padding. The component handles the link; Tailwind classes, such as text-2xl and font-semibold, complement the typography. Class order in the attribute does not determine which rule wins when there is a conflict.

Text and background colors

The families are primary, secondary and asset, each with the variants hard and soft. Combine the prefix with one of these six options:

Format Example Application
tbu-text-* tbu-text-asset-hard Text color.
tbu-bg-* tbu-bg-secondary-hard Solid background color.
tbu-bg-glass-* tbu-bg-glass-asset-hard Background color mixed with transparency, using --opacity.

For example, tbu-text-asset-hard reads --color-tb-asset-hard. The available suffixes are primary-hard, primary-soft, secondary-hard, secondary-soft, asset-hard and asset-soft. 

<div class="tbu-bg-secondary-hard tbu-text-primary-soft tbu-rounded p-4">
  Dark background with light text.
</div>
<div class="tbu-bg-glass-asset-hard tbu-rounded p-4">
  Accent background with transparency.
</div>

Transparency affects only this class's background, not its text or children. The appearance also depends on the surface behind it.

Organization and spacing

Class Effect
tbu-container Responsive horizontal padding, defined by --container-*.
tbu-block Responsive vertical padding, defined by --block-*.
tbu-flex-cols Column flex layout with wrapping and theme spacing.
tbu-flex-rows Row flex layout with wrapping and theme spacing.
tbu-grid-1, tbu-grid-2, … Grid with the specified number of columns and theme spacing.

The linear layout already applies tbu-container to the main area. In page fragments, use tbu-block for vertical spacing and avoid duplicating horizontal padding unnecessarily. 

<div class="tbu-grid-1 md:tbu-grid-2 lg:tbu-grid-3">
  <article class="tbu-panel"><h3>Content</h3><p>HTML fragments.</p></article>
  <article class="tbu-panel"><h3>Components</h3><p>Reusable features.</p></article>
  <article class="tbu-panel"><h3>Theme</h3><p>Shared values.</p></article>
</div>

Without responsive prefixes, tbu-grid-3 keeps three columns at any width. The combination above starts with one column, switches to two at 48rem and three at 64rem.

tbu-container and tbu-block have five ranges: base, md (48rem), lg (64rem), xl (80rem), and 2xl (96rem). Flex and grid utilities use --gap-sm, --gap-md and --gap-lg.

Borders and visual details

Class or format Effect
tbu-border-* Border on all four sides, using a color from the chosen family.
tbu-border-top-*, tbu-border-right-*, tbu-border-bottom-*, tbu-border-left-* Border only on the specified side.
tbu-rounded Corner radius from --rounded.
tbu-shadow Shadow from --shadow-color.
tbu-texture Image from --texture repeated in the background.
tbu-duration Transition duration from --duration and an ease-in-out curve.

Borders need a color suffix, such as tbu-border-secondary-soft or tbu-border-bottom-asset-hard. Thickness and style come from --border-width and --border-style. 

<div class="tbu-border-secondary-soft tbu-rounded tbu-shadow p-4">
  Content with a border and shadow.
</div>

tbu-duration does not choose the animated property or handle reduced motion on its own. When adding animations, define transition properties and respect the visitor's preference.

Panels, terms, and code examples

tbu-panel combines a background, texture, left border, and padding, configured by the variables --panel-*. It can display notices, cards, or code blocks. Add tbu-rounded if you want rounded corners. 

<pre class="tbu-panel tbu-rounded max-w-full overflow-x-auto p-4 text-sm"><code>npm run build</code></pre>
<p>Use <code class="tbu-text-asset-soft font-mono">tbc-link</code> to navigate.</p>

Inside pre > code, escape markup characters: write &lt; for <, &gt; for > and &amp; for &. This keeps the example as text, without mounting components or HTML elements.

Utilities used by components

Utility Preferred component
tbu-link tbc-link
tbu-nav tbc-nav
tbu-header tbc-header
tbu-footer tbc-footer
tbu-layout-linear tbc-layout-linear
tbu-sidebar and tbu-backdrop tbc-sidebar

These classes provide styling; they do not create slots, open/close actions, or the components' internal structure. Prefer the corresponding tag when you need those features. A regular HTML link can also use tbu-link.

For responsive navigation, prefer tbc-nav responsive with the slots nav-wide and nav-narrow. The attribute vertical arranges items in a column. See the examples in the guide to .

Preparing content for publishing

Write complete class names in fragments. Tailwind generates CSS during the build: when introducing a new class, run npm run build and publish the generated CSS too. Copying only the updated HTML may not include that class's styles.
