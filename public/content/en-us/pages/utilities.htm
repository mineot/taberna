Utilities

Utilities are classes that apply visual rules to HTML elements. In Taberna, the project's own classes use the tbu-* prefix and live in src/styles/utilities.css.

You can combine them to present the content with the project's colors, borders, textures, and spacing. This page explains what each class does and how to use it in the HTML fragments.

The relationship between utilities and the theme

The theme defines shared values, and the utilities apply those values to elements. For example, --color-secondary holds a color in the theme, while tbu-secondary-bg uses that color as the background. 

<div class="tbu-secondary-bg tbu-primary-text p-4">
  <p>Content with a secondary background and main text.</p>
</div>

In this example, the two tbu-* classes apply Taberna's colors. The Tailwind class p-4 adds inner padding.

Changing the variable in the theme updates the elements that use it. Adding the class to the HTML defines where that setting will be applied. To learn about the values and their customization options, see the themes page.

How to combine classes

Use Taberna's utilities together with Tailwind classes according to each one's responsibility: 

<section class="tbu-secondary-bg tbu-border tbu-rounded flex flex-col gap-4 p-6">
  <h2 class="tbu-asset-text text-2xl font-bold">My project</h2>
  <p class="tbu-primary-text">A brief presentation of the work.</p>
</section>

Here, the project's own classes provide colors, border, and rounding. The others arrange the elements in a column, create space between them, and adjust the typography.

Avoid combining classes that compete for the same property without a clear intention. The order in which the names appear in the class attribute does not by itself determine which rule wins; the result depends on the cascade of the generated CSS.

The examples in this guide are HTML snippets to use after converting this draft. Taberna does not interpret Markdown automatically.

Background and text colors

Each color family offers a background utility, a background utility with transparency, and a text utility:

Class Value used
tbu-primary-bg --color-primary
tbu-primary-bg-opaque --color-primary-opaque
tbu-primary-text --color-primary-soft
tbu-secondary-bg --color-secondary
tbu-secondary-bg-opaque --color-secondary-opaque
tbu-secondary-text --color-secondary-soft
tbu-asset-bg --color-asset
tbu-asset-bg-opaque --color-asset-opaque
tbu-asset-text --color-asset-soft

The text classes use the soft variations, not the family's base color. The classes ending in bg-opaque, despite the name, use colors that are currently mixed with transparency in the theme.

Backgrounds and texts are configured separately. Applying a background class does not automatically choose a text color with adequate contrast. 

<div class="tbu-asset-bg-opaque tbu-primary-text p-4">
  <p>A highlighted piece of information with a translucent background.</p>
</div>

Because the background is translucent, the appearance also depends on what is behind it. Check how the text reads in the site's final combination.

Links and highlight elements

tbu-asset-link

tbu-asset-link applies the --color-asset-soft color, a pointer cursor, and the shared transition duration. On hover, the color is mixed with 10% black; during activation, with 20% black. 

<a class="tbu-asset-link underline" href="#/pages/howwork.htm">
  Learn how Taberna works
</a>

The utility does not add an underline, a font size, or a specific focus style. In the example, the underline comes from the underline class. Also make sure there is a visible focus indication in the final presentation of the links.

tbu-asset-pill

tbu-asset-pill combines highlight text, flex display, rounded-sm rounding, horizontal px-2 and vertical py-1 padding, a pointer cursor, and the transition duration.

In the normal state, it does not define a background color. On hover, it applies --color-asset to the background and --color-primary to the text. During activation, it darkens the background with a 10% black mix. 

<a class="tbu-asset-pill w-fit" href="#/pages/templates.htm">
  Explore templates
</a>

This utility's rounding uses rounded-sm; it is not controlled by the --rounded variable. The w-fit class in the example limits the link's width to its content.

These utilities provide presentation. To navigate, use a link with href; to perform an action, use a button with the corresponding behavior. Applying the class to a div does not create navigation, action, or keyboard interaction.

Text and code panels

tbu-asset-code-text

tbu-asset-code-text combines the highlight color used by tbu-asset-text, a monospace font, and a light weight. It is useful for file names, commands, and other technical terms inside a paragraph. 

<p>
  Edit the <code class="tbu-asset-code-text">theme.css</code> file
  to customize the theme variables.
</p>

tbu-asset-code-panel

tbu-asset-code-panel creates a panel with a secondary background, p-4 padding, text-lg font size, and a flex column layout with gap-1.

It also recognizes two types of direct children:

Direct child Presentation
span.terminal Uses tbu-asset-code-text and receives a visual marker before the text.
span.css Uses the highlight color, serif font, text-base size, and semibold weight.

To present commands:

<div class="tbu-asset-code-panel">
  <span class="terminal">npm install</span>
  <span class="terminal">npm run dev</span>
</div>

The terminal marker is inserted by a CSS pseudo-element and is not part of the written command. It is configured not to be selectable.

To present CSS declarations:

<div class="tbu-asset-code-panel">
  <span class="css">--color-asset: var(--color-blue-500);</span>
  <span class="css">--color-asset-soft: var(--color-blue-300);</span>
</div>

The selectors require these span elements as direct children of the panel. Inserting another element between the panel and the span elements prevents those specific rules from being applied.

The panel does not run commands, does not copy text to the clipboard, and does not do automatic syntax highlighting. It also does not preserve spaces and line breaks like a pre element. For other code formats, choose the appropriate HTML structure and styles. When showing HTML tags as text, escape characters such as < using &lt;.

Borders and rounding

The border utilities apply the color, thickness, and style defined by --border-color, --border-size, and --border-style.

Class Where the border is applied
tbu-border All sides.
tbu-border-top Top side.
tbu-border-right Right side.
tbu-border-bottom Bottom side.
tbu-border-left Left side.

To create a separation above a piece of content:

<div class="tbu-border-top pt-4">
  <p>Complementary information.</p>
</div>

The padding in the example comes from pt-4; the border utility does not create inner space.

tbu-rounded applies the radius defined in --rounded. You can combine it with a border and a background: 

<div class="tbu-border tbu-rounded tbu-secondary-bg tbu-primary-text p-4">
  <p>A panel with the theme's shared appearance.</p>
</div>

The rounding does not add overflow: hidden. If you need to clip the inner content at the corners, handle that behavior separately.

Texture, shadow, and overlay

tbu-texture

tbu-texture uses the image defined in --texture and repeats it on the background. The background color remains the responsibility of another rule. 

<div class="tbu-secondary-bg tbu-texture tbu-primary-text p-6">
  <p>Content with a background color and texture.</p>
</div>

Setting --texture: none in the theme disables the image on elements that use this utility.

tbu-shadow

tbu-shadow applies two shadow layers with the color from --shadow-color. If that variable is missing, it uses black with transparency as a fallback. 

<div class="tbu-secondary-bg tbu-primary-text tbu-rounded tbu-shadow p-4">
  <p>A panel highlighted by a shadow.</p>
</div>

The color is configurable through the theme; offsets and blurs are defined in the utility itself. The class does not add border, background, or rounding automatically.

tbu-backdrop

tbu-backdrop was created for overlays, such as the one behind the sidebar. It combines fixed positioning, inset-0, texture, backdrop-blur-xs background blur, the --z-backdrop layer, and the --backdrop-color color.

It is meant to cover the screen area and can block interactions with what is below. Opening, closing, click handling, and focus management belong to the component that uses this overlay; they are not implemented by the utility.

In the theme's current configuration, --backdrop-color references --color-secondary-bg, which is not defined. Therefore, its color declaration does not provide a valid value. The themes page explains this limitation and presents an adjustment option; texture, blur, and positioning are rules independent of that color.

Responsive spacing

tbu-container applies horizontal padding using padding-inline. tbu-block applies vertical padding using padding-block.

Both utilities select variables according to the screen width:

Width tbu-container tbu-block
Below 48rem --container-sm --block-sm
From 48rem up to before 64rem --container-md --block-md
From 64rem up --container-lg --block-lg

The final value is calculated by multiplying the chosen variable by --spacing. The current container values are 4, 14, and 24; the block values are 6 in all three ranges. 

<section class="tbu-container tbu-block">
  <h2>A region with responsive spacing</h2>
  <p>The padding follows the values defined in the theme.</p>
</section>

tbu-container does not define a maximum width or center the element. tbu-block does not change its display type to display: block; its role is to apply vertical padding. Both also include tbu-duration.

In the default template, the main area already uses tbu-container. Reapplying the utility inside it adds another level of padding. Use that composition when you want the extra space, or apply only tbu-block and other local classes when the outer horizontal space is already enough.

Transition duration

tbu-duration defines the duration from --duration and the ease-in-out transition curve. The theme's current value is 200ms.

It does not create a new visual state or explicitly choose which properties should change. Combine it with the transition property and the desired states: 

<a
  class="tbu-primary-text tbu-duration transition-colors hover:tbu-asset-text"
  href="#/pages/themes.htm"
>
  Explore the theme
</a>

In this example, transition-colors defines the group of properties, hover:tbu-asset-text changes the color on hover, and tbu-duration provides the time and curve.

The utility does not control all the site's animations and does not automatically disable motion according to the visitor's preference. When creating transitions, consider using reduced-motion variants and preserve the interaction's focus states.

Creating your own utilities

You can add reusable classes to src/styles/utilities.css with @utility, following the tbu-* prefix and reusing theme values.

For example, this definition would create a utility for small panels:

@utility tbu-panel {
  @apply tbu-secondary-bg tbu-primary-text tbu-border tbu-rounded p-4;
}

After adding it to the project, the usage would be:

<div class="tbu-panel">
  <p>Panel content.</p>
</div>

tbu-panel is only an example; it is not currently defined. The name must be unique, and the rule should gather behavior that makes sense to reuse.

A utility serves shared uses. For styles specific to a page or structure, prefer a dedicated selector in src/style-customs.css, as the project already does with .page-custom.

When using Tailwind directives in a Vue component style block, include @reference "@/style.css"; at the beginning. That reference lets the block use the project's shared definitions.

Keep the full class names in the source files and generate a new build when adding classes to the content or new utilities. Fragments are loaded at runtime, but the CSS is generated during the build; a new class written only in already published content may not exist in the distributed CSS.

Complete example

The example below combines utilities in a presentation section. It assumes the horizontal spacing has already been applied by the template's main area: 

<section class="tbu-block">
  <div class="tbu-secondary-bg tbu-primary-text tbu-border tbu-rounded tbu-shadow flex flex-col gap-4 p-6">
    <h2 class="tbu-asset-text text-2xl font-bold">Customize your Taberna</h2>
    <p>
      Organize the content, choose the colors, and adapt the presentation to your project.
    </p>
    <p>
      The shared settings live in
      <code class="tbu-asset-code-text">theme.css</code>.
    </p>
    <a
      class="tbu-asset-link w-fit underline focus-visible:outline-2 focus-visible:outline-offset-2"
      href="#/pages/themes.htm"
    >
      Learn about the theme settings
    </a>
  </div>
</section>

Check the result with your theme's colors, at different widths, and using the keyboard. The utilities help maintain consistency, but the final combination should preserve contrast, visible focus, and enough space for the content.
