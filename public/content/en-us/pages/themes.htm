Theme

The theme brings together Taberna's shared colors, fonts, spacing, and visual details. Its definitions live in src/styles/theme.css and are used by components prefixed with tbc-* and utilities prefixed with tbu-*.

The block @theme defines fonts and colors integrated with Tailwind. The block :root contains variables for spacing, visual details, and component appearance. Change the existing values to customize your site.

Color palette

Variable in @theme Current value Role
--color-tb-primary-hard var(--color-neutral-600) Main background.
--color-tb-primary-soft var(--color-neutral-200) Main text.
--color-tb-secondary-hard var(--color-stone-900) Dark secondary surfaces.
--color-tb-secondary-soft var(--color-stone-400) Borders and secondary information.
--color-tb-asset-hard var(--color-emerald-400) Accent color.
--color-tb-asset-soft var(--color-emerald-100) Soft accent variant.

The names represent roles in the theme. For example, tbu-bg-secondary-hard applies the dark secondary background, and tbu-text-asset-hard applies the accent color to text. Each of the six colors can be used for text, backgrounds, and borders.

For a blue accent, replace these values in the block @theme: 

--color-tb-asset-hard: var(--color-blue-400);
--color-tb-asset-soft: var(--color-blue-100);

Variables that reference these colors follow the change. Links have their own values in --link, --link-hover and --link-active; adjust those too if you want them to match the new identity.

Fonts are hosted within the project, in public/fonts/, and declared in src/styles/helpers/fonts.css. To replace a family, prepare the files and their declarations, update the corresponding variable, and review the preloads in index.html.

Responsive spacing

tbu-container applies horizontal padding, and tbu-block applies vertical padding. The numbers below multiply --spacing, whose default Tailwind base is 0.25rem; they are not pixel values.

Screen range Suffix --container-* --block-*
Below 48rem sm 4 4
48rem and above md 12 5
64rem and above lg 24 6
80rem and above xl 46 7
96rem and above 2xl 96 8

The larger range overrides the previous one. The suffix sm on these variables is the initial value; it does not wait for Tailwind's breakpoint sm:.

The utilities tbu-flex-cols, tbu-flex-rows and tbu-grid-* use --gap-sm: 4, --gap-md: 3 and --gap-lg: 2. Their gaps decrease in the two wider ranges. 

--container-md: 10;
--container-lg: 18;
--container-xl: 28;
--container-2xl: 40;

--block-sm: 4;
--block-md: 5;
--block-lg: 6;
--block-xl: 7;
--block-2xl: 8;

This example reduces horizontal padding on larger screens. High values leave less width for content. Explicit classes, such as p-4 and gap-2, are not controlled by these variables.

Borders, texture, and transparency

Variable in :root Current value Application
--border-width 1px Thickness of borders that use the theme.
--border-style solid Style of those borders.
--rounded var(--radius-md) tbu-rounded.
--texture url('/images/texture.png') tbu-texture.
--opacity 30% Color proportion in glass backgrounds and loading/error backgrounds.
--duration 200ms Duration in tbu-duration.
--shadow-color Secondary hard color at 100% Color of tbu-shadow.
--backdrop-color Secondary hard color at 80% Backdrop behind the sidebar.

A general border gets its color from the class suffix, such as tbu-border-asset-hard. The header, footer, menu, and panel have their own variables for the complete border.

To remove the texture, use --texture: none;. To replace it, place the image in public/images/ and change the path. The background color remains defined by the color rules.

--opacity controls only expressions that reference it. The header, footer, and backdrop use their own 80% mixes; the carousel indicator uses 40%.

Panels

Variable Current value Effect on tbu-panel
--panel-bg var(--color-tb-secondary-hard) Background color.
--panel-border 5px solid var(--color-tb-asset-hard) Left border.
--panel-border-spacing 5 Left padding in spacing units.
--panel-spacing 2 Vertical and right padding in spacing units.

The panel also applies the texture. Use these values to adjust notices, cards, and examples that use tbu-panel.

Layers and motion

The backdrop uses --z-backdrop: 100, and the sidebar uses --z-sidebar: 150. Keep the panel above its backdrop. The variable --z-loader: 999 is declared, but the current loading widget does not use it.

--duration does not change the carousel interval or the loading animation. The carousel already accounts for reduced motion; the duration utility alone does not implement this behavior for other elements.

Customization example

After changing the two accent colors in @theme, you can adjust these settings in the existing block :root: 

--link: var(--color-blue-300);
--link-hover: var(--color-blue-200);
--link-active: var(--color-blue-100);
--rounded: 0.75rem;
--panel-border: 3px solid var(--color-tb-asset-hard);
--panel-border-spacing: 4;
--panel-spacing: 4;

Check contrast, readability, focus, and spacing at narrow and wide screen sizes. Run npm run build and review the result with npm run preview. To apply these settings to fragments, continue with the guide to .
